1. ОБЗОР ПРОЕКТА
----------------
Этот проект — встроенный внутриигровой трейнер / мод-меню для игры Raft (Unity C#).
Код компилируется в одну управляемую сборку RaftTrainer.dll.
Сборка загружается игрой автоматически при старте через вызов из Assembly-CSharp.dll:
  RaftTrainer.TrainerGUI.Init()

4. ПРАВИЛА И СТАНДАРТЫ КОДА ДЛЯ ИИ
----------------------------------
- Совместимость C#:
    Целевой компилятор поддерживает C# 5.0 - 7.3 (.NET Framework 4.0 / 4.7.2).
    НЕ используйте фичи C# 8.0+ (nullable-аннотации '?', switch-выражения '=>', 'is not null').
- Система GUI:
    Использует Unity IMGUI в OnGUI().
    КРИТИЧЕСКОЕ ПРАВИЛО: НИКОГДА не вызывайте методы GUILayout или GUI внутри метода Update() или вне OnGUI(). Это вызывает исключение InvalidOperationException в Unity.
- Производительность и таймеры (Троттлинг):
    НЕ вызывайте тяжелые методы вроде FindObjectsOfType<T>() каждый кадр в Update() или OnGUI().
    Любые сканирования мира (грядки, животные, акулы, клады, сундуки, батарейки) ОБЯЗАНЫ быть на таймере с интервалом от 0.35с:
      if (Time.time > nextThrottleTime) { nextThrottleTime = Time.time + 0.35f; ... }
    Для рендера ESP используйте кэшированные списки (cachedSharksInfo, cachedPickups, cachedTreasures, cachedOres).
- Рефлексия (Reflection):
    Все приватные поля игры кэшируются один раз при старте в static readonly FieldInfo:
      private static readonly FieldInfo fSharkCanAttack = typeof(Shark).GetField("canAttack", BindingFlags.Instance | BindingFlags.NonPublic | BindingFlags.Public);
- Защита от сбоев (Try-Catch):
    Любое обращение к игровым объектам оборачивайте в try { ... } catch {}, чтобы ошибка на одном объекте не роняла весь трейнер.

5. КАК ДОБАВИТЬ НОВУЮ ФУНКЦИЮ (ПОШАГОВО)
----------------------------------------
Шаг 1: Объявить переменную / переключатель в классе TrainerGUI:
    public bool myFeature = false;
    public float myValue = 10f;

Шаг 2: Если нужен доступ к приватным полям игры, объявить кэш FieldInfo в начале класса:
    private static readonly FieldInfo fTarget = typeof(TargetClass).GetField("fieldName", BindingFlags.Instance | BindingFlags.NonPublic | BindingFlags.Public);

Шаг 3: Написать метод реализации:
    private void ApplyMyFeature(Network_Player player)
    {
        try
        {
            if (player == null) return;
            // Ваша логика
        }
        catch {}
    }

Шаг 4: Вызвать метод в Update():
    if (myFeature) ApplyMyFeature(player);
    // Или внутри блока троттлинга, если метод сканирует объекты сцены.

Шаг 5: Добавить кнопку или тумблер в соответствующий таб интерфейса (RaftTrainer.Menu.cs):
    myFeature = DrawModuleToggle("Моя функция", myFeature);
    Если нужно, чтобы фича появилась в глобальном поиске, HUD активных читов и профилях —
    добавьте русскую подпись в словарь featureLabels (RaftTrainer.V12.cs).
    ЛЮБОЕ новое публичное bool/float/int поле автоматически попадает в профили
    (SaveProfileFile сериализует все публичные поля через рефлексию).

- F12: ESP вкл/выкл
- O: Сортировка инвентаря (перебинживается, по умолчанию O)

- X или ПКМ (зажать): Захват цели аимботом (на животных / акулу / предметы)
- WASD + Space (Вверх) + Левый Ctrl (Вниз): Управление в режиме полета (Fly Mode)
- Space + W в воздухе: Планирование в свободном полете по воздуху (Zipline Air)

- W под водой (при включенном подводном скутере): рывок вперед по взгляду
- WASD / Space / Ctrl (при оседланной акуле): управление акулой
- Все F-клавиши выше можно переназначить в табе СИСТЕМА (клик по кнопке клавиши).

9. ЗАМЕТКИ ПО API ИГРЫ (v13)
----------------------------
- Расширение плота (+3x3/+5x5) ПЕРЕПИСАНО в v13: старый код передавал ЛОКАЛЬНУЮ позицию
  в статический SnapBuildPosition (который работает с МИРОВЫМИ координатами) и накапливал
  ошибку float-шагом — из-за этого блоки не ставились. Новый алгоритм (BatchExpandRaftFoundations
  + TryPlaceExpanded в RaftTrainer.cs): local -> raft.transform.TransformPoint -> SnapBuildPosition
  -> InverseTransformPoint, защита от дублей по ключу (x/z в половинках клетки), высота baseY
  берётся из существующего Block_Foundation, есть резервный путь наращивания от крайних
  фундаментов ровным шагом BlockCreator.BlockSize. Та же схема снапа применена в PasteRaftBlueprint.
- Fuel (компонент машин): GetFuelCount(), MaxFuel, AddFuel(int), IsBurning() — публичные.
  Инвентарь сундука: Storage_Small.GetInventoryReference() -> Inventory.GetItemCount("Plank") /
  RemoveItem("Plank", 1). Используется авто-дозаправкой и дашбордом машин.
- Урожай: Plant.FullyGrown(), GetGrowTimer(), growTime (публичные) — ESP урожая в процентах.
- Погода/ночь: UnityEngine.AzureSky.AzureSkyController.IsDaytime — быстрая ночь ускоряет
  Time.timeScale только когда ночь; при наступлении дня возвращает 1.0.
- Статистика v13: убийства акул по stat_health.IsDead() у Shark, смерти по player.Stats,
  острова по близости к Landmark (<150м, HashSet по GetInstanceID), потеря блоков по дельте
  количества Block (обновляется раз в 3 сек для тахометра).
