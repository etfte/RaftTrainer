1. ОБЗОР ПРОЕКТА
----------------
Этот проект — встроенный внутриигровой трейнер / мод-меню для игры Raft (Unity C#).
Код компилируется в одну управляемую сборку RaftTrainer.dll.
Сборка загружается игрой автоматически при старте через вызов из Assembly-CSharp.dll:
  RaftTrainer.TrainerGUI.Init()

Версия архитектуры: Titan v14.0 (все модули расширений v12, v13, v14 объединены
в единый актуальный исходник RaftTrainer.V14.cs).

4. ПРАВИЛА И СТАНДАРТЫ КОДА ДЛЯ ИИ
----------------------------------
- Совместимость C#:
    Целевой компилятор поддерживает C# 5.0 - 7.3 (.NET Framework 4.0 / 4.7.2).
    НЕ используйте фичи C# 8.0+ (nullable-аннотации '?', switch-выражения '=>', 'is not null').
- Система GUI:
    Использует Unity IMGUI в OnGUI().
    КРИТИЧЕСКОЕ ПРАВИЛО: НИКОГДА не вызывайте методы GUILayout или GUI внутри метода Update()
    или вне OnGUI(). Это вызывает InvalidOperationException в Unity.
- Производительность и таймеры (Троттлинг):
    НЕ вызывайте тяжелые методы вроде FindObjectsOfType<T>() каждый кадр в Update() или OnGUI().
    Любые сканирования мира (грядки, животные, акулы, клады, сундуки, батарейки) ОБЯЗАНЫ быть
    на таймере с интервалом от 0.3с. Для рендера ESP используйте кэшированные списки.
- Рефлексия (Reflection):
    Все приватные поля игры кэшируются один раз при старте в static readonly FieldInfo.
- Защита от сбоев (Try-Catch):
    Любое обращение к игровым объектам оборачивайте в try { ... } catch {}, чтобы ошибка
    на одном объекте не роняла весь трейнер.

5. КАК ДОБАВИТЬ НОВУЮ ФУНКЦИЮ (ПОШАГОВО)
----------------------------------------
Шаг 1: Объявить переменную / переключатель в классе TrainerGUI (RaftTrainer.V14.cs или RaftTrainer.cs):
    public bool myFeature = false;
    public float myValue = 10f;

Шаг 2: Если нужен доступ к приватным полям игры, объявить кэш FieldInfo:
    private static readonly FieldInfo fTarget = typeof(TargetClass).GetField("fieldName", BindingFlags.Instance | BindingFlags.NonPublic | BindingFlags.Public);

Шаг 3: Написать метод реализации:
    private void ApplyMyFeature(Network_Player player)
    {
        try
        {
            if (player == null) return;
            // Логика
        }
        catch {}
    }

Шаг 4: Вызвать метод в UpdateV14Features(player) или Update():
    if (myFeature) ApplyMyFeature(player);

Шаг 5: Добавить кнопку или тумблер в нужный таб интерфейса (RaftTrainer.Menu.cs):
    myFeature = DrawModuleToggle("Моя функция", myFeature);
    Для поддержки глобального поиска и профилей добавьте русскую подпись в словарь
    featureLabels (RaftTrainer.V14.cs). Все публичные поля автоматически сериализуются в профили.

8. ЗАМЕТКИ ПО ИГРОВЫМ API RAFT
------------------------------
- Вся интеграция построена на чистом коде через сборки UnityEngine и Assembly-CSharp:
  * Движение плота: Raft.AddForce(dir, force, ForceMode.Acceleration, true)
  * Погода: WeatherManager.GetCurrentWeatherType() и свойство WeatherTimer
  * Топливо машин: Fuel.GetFuelCount(), MaxFuel, AddFuel(int), IsBurning()
  * Сундуки: Storage_Small.GetInventoryReference() -> Inventory.GetItemCount / RemoveItem
  * Батареи: BatteryCharger.RechargeBattery (через кэшированную рефлексию)
  * Урожай: Plant.FullyGrown(), GetGrowTimer(), growTime
  * Гнёзда: BirdsNest.AllNests, HasEgg/HasFeather, PickupEgg/PickupFeather
  * Радар: Reciever.SetFrequencyIndexCheat(index)
  * Рыбалка: FishingBaitHandler.EquipBait(item), FishingRod.PullItemsFromSea (рефлексия)
  * Карта и визуал: Camera.main.WorldToScreenPoint, GUIUtility.RotateAroundPivot
