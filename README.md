Комплексный внутриигровой трейнер и полнофункциональное мод-меню нового поколения для игры **Raft** (Unity C#). Проект скомпилирован в единую высокооптимизированную сборку `RaftTrainer.dll` с нулевыми аллокациями в горячих циклах (Zero-Alloc) и максимальной частотой кадров.

Точка входа внедрения в игровой рантайм `Assembly-CSharp.dll`:
```csharp
RaftTrainer.TrainerGUI.Init()
```

## ⚡ Оптимизация производительности (Titan Architecture)

В коде реализован масштабный комплекс низкоуровневых оптимизаций, устраняющий влияние мода на частоту кадров и сборщик мусора Unity:

1. **Ликвидация сканирований графа сцены (`FindObjectsOfType`)**:
   - Все тяжелые вызовы `FindObjectsOfType` заменены на интервальное кеширование с троттлингом (0.5 – 4.0 сек) и проверку компонентов локального игрока в первую очередь (`GetComponentInChildren`).
   - Кешируются: луки, гарпуны, метательные снаряды, чайки, грядки, растения, сундуки, двигатели, печи, баки, батареи, зарядники, спринклеры, фонари, металлоискатели и крысы.
2. **Нулевая тригонометрия и вычисления расстояний (Zero-Sqrt Distance)**:
   - Все проверки расстояний переведены на квадратичные дистанции (`sqrMagnitude` и скалярное произведение `Vector3.Dot`).
   - Сортировка подбираемого лута оптимизирована через структуру `PickupDistEntry` с предрассчитанным `sqrDist`, исключая 350+ вызовов `transform.position` внутри компаратора.
3. **Ликвидация мусора в рендере (Zero-Alloc IMGUI & ESP)**:
   - `RaftTrainer.Menu.cs`: вызовы `GUILayout.Height(...)` заменены на предвыделенные статические массивы `OptHeight18`, `OptHeight20`, `OptHeight22`, `OptHeight24`, `OptHeight26`, исключая свыше 110 аллокаций массивов за каждый кадр.
   - `DrawOutlineRect`: отрисовка рамок ESP переведена на единую статическую структуру `outlineRect` (0 аллокаций `new Rect`).
   - Все цветовые палитры (ESP блоков, линеек, тепловизора, миникарты, карты мира) вынесены в статические `readonly Color`.
4. **Кеширование рефлексии и пулы объектов**:
   - Методы и поля компонентов движка Raft закешированы статически (`mRechargeBattery`, `mPullItems`, `mWeighAnchor`, `fHungerTimer` и др.).
   - Вызовы `MethodInfo.Invoke` используют переиспользуемый статический массив аргументов `rechargeArgs[1]`.
   - Пулы коллекций: `cachedEntities`, `cachedPickups`, `cachedPlayers`, `cachedSharksInfo`, `sharkInfoPool`, `espNameSharkPool`, `espTagPool`.

## 🚀 Инструкция по сборке

### Вариант 1: Сборка в 1 клик через `build.bat` (Рекомендуется)
Запустите файл `build.bat`:
```cmd
build.bat
```
Скрипт использует компилятор .NET Framework `csc.exe` с флагом `/optimize+`, собирает проект и автоматически копирует готовую `RaftTrainer.dll`:
1. В папку игры: `D:\Raft\Raft_Data\Managed\RaftTrainer.dll`
2. Копию на Рабочий стол: `%USERPROFILE%\Desktop\RaftTrainer.dll`
3. В папку OneDrive Рабочего стола (при наличии)

### Вариант 2: Сборка через .NET CLI
```powershell
dotnet build -c Release
```

## 🎮 Установка в игру

1. Скомпилируйте проект или скопируйте готовую `RaftTrainer.dll` в директорию `Raft\Raft_Data\Managed\`.
2. Добавьте вызов `RaftTrainer.TrainerGUI.Init()` в метод инициализации игры (например, в `Assembly-CSharp.dll` через dnSpy).
3. Запустите игру. По умолчанию меню чита скрыто, нажмите <kbd>F4</kbd> или <kbd>Insert</kbd> для вызова.
