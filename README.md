Комплексный внутриигровой трейнер и мод-меню нового поколения для игры **Raft** (Unity C#). Код компилируется в одну управляемую сборку `RaftTrainer.dll` и внедряется в игровой рантайм `Assembly-CSharp.dll` через точку входа:
```csharp
RaftTrainer.TrainerGUI.Init()
```

---

## 🌟 Ключевые возможности

| Раздел | Описание функционала |
| :--- | :--- |
| **⚔️ БОЙ (Combat)** | **Ван-Хит Кил (1-Hit Kill)**, настраиваемый множитель урона оружия, аура отпугивания хищников, мирная акула, триггербот, вечные и лазерные стрелы, лук без задержки, бесконечные сети гарпуна, векторные аимботы на животных/предметы, мгновенное уничтожение всех врагов. |
| **🏃 БЕГ & ПЕРЕДВИЖЕНИЕ** | Свободный полёт (**Fly Mode**), планирование в воздухе (**Zipline Air**), подводный скутер, супер-скорость и мега-прыжок, бесконечный кислород, моментальный телепорт на плот, 10 слотов сохранения точек мира, **спасательный крюк** (возврат на плот при падении за борт). |
| **👁️ ВИЗУАЛ & ESP** | Высокопроизводительный **ESP** (игроки, акулы, руда, клады, бочки, предметы) с троттлингом и экранным отсечением, **глобальная радарная карта мира** с кольцами 250/500/1000м, 30-секундный след акул, ESP-трассеры, **тепловизор хищников сквозь стены**, радар сюжетных частот. |
| **👤 ИГРОК & СТРОЙКА** | **Режим бога (GodMode)**, неиссякаемая сытость/жажда, вечная прочность экипировки, бесплатный крафт и стройка без опор, дупликатор, удалённый доступ к сундукам, разблокировка всех рецептов, чертежей и персонажей, **снимок/восстановление инвентаря**, просмотр сумок союзников. |
| **⛵ ПЛОТ & АВТОПИЛОТ** | Неразрушимый плот, **автопилот тяги к островам** с авто-якорем по прибытии, **строительная линейка A-B**, выделение блоков ЛКМ (массовый ремонт, покраска, снос), чертёжник фундамента и **копир этажей** со сдвигом по высоте, стабилизация качки и антикрен. |
| **🌾 ФЕРМА & ЭКОЛОГИЯ** | **Авто-сбор гнёзд птиц** (перья и яйца), **авто-посадка семян** по свободным грядкам, ESP стадий созревания урожая, авто-полив, режим шторма (бесконечный дождь), сытые питомцы, авто-крысолов, калькулятор биореактора. |
| **⚙️ АВТОМАТИЗАЦИЯ** | **Авто-дозаправка двигателей** биотопливом из сундуков, авто-подзарядка разряженных батарей, **профессиональная рыбалка 2.0** (авто-наживка и авто-подсечка), авто-выброс мусора по ID-фильтрам, **макро-рутина в 1 клик** (7 бытовых действий подряд). |
| **📊 СИСТЕМА & HUD** | Неограниченные профили настроек (`RaftTrainer_Profiles/*.txt`), переназначение горячих клавиш в 1 клик, оверлеи: **тахометр FPS**, дашборд двигателей, таймер погоды, карта, **умные напоминания** (топливо, батареи, урожай), сигнализация акул, быстрая ночь. |
| **📦 СПАВНЕР** | Каталог всех предметов игры с иконками, поиск, категории, регулировка количества, 3 персональных набора-пресета, кисть спавна животных кликом. |

## ⌨️ Горячие клавиши (по умолчанию)

| Клавиша | Функция | Описание |
| :---: | :--- | :--- |
| <kbd>F4</kbd> / <kbd>Insert</kbd> | **Главное меню** | Открыть или скрыть графическое окно чита (по умолчанию скрыто) |
| <kbd>F1</kbd> | **Режим бога (GodMode)** | Бессмертие, бесконечное здоровье, сытость, жажда и кислород |
| <kbd>F2</kbd> | **Режим полёта (Fly)** | Свободный полёт (WASD + Space вверх + LCtrl вниз) |
| <kbd>F5</kbd> | **Телепорт на плот** | Моментальный возврат в центр базового плота |
| <kbd>F6</kbd> | **Фото-режим** | Чистый скриншот без оверлеев и меню в корневую папку игры |
| <kbd>F7</kbd> | **Макро-рутина** | 7 действий за секунду: ТП → ремонт → сортировка → сетки → полив... |
| <kbd>F8</kbd> | **Возврат в слот 1** | Телепортация в сохранённую быструю точку |
| <kbd>F9</kbd> | **Автопилот плота** | Курс на ближайший остров с автоматической постановкой на якорь |
| <kbd>F10</kbd> | **Строительная линейка** | ЛКМ ставит точки A и B, рассчитывая точную дистанцию в метрах |
| <kbd>F12</kbd> | **ESP переключатель** | Включение / отключение всех оверлеев и меток мира |
| <kbd>O</kbd> | **Сортировка сумок** | Мгновенная сортировка и группировка предметов в рюкзаке |
| <kbd>Z</kbd> *(зажать)* | **Eagle Eye Zoom** | Зум камеры без необходимости брать бинокль |
| <kbd>X</kbd> / <kbd>ПКМ</kbd> | **Аимбот** | Захват прицела на хищниках, животных или луте |
| <kbd>Space</kbd> + <kbd>W</kbd> | **Zipline Air** | Свободное планирование в воздухе при прыжке |

> *Все функциональные клавиши можно переназначить в реальном времени во вкладке меню **«СИСТЕМА»**.*

## 🚀 Инструкция по сборке

### Вариант 1: Сборка в 1 клик через `build.bat` (Рекомендуется)
Запустите файл `build.bat`:
```cmd
build.bat
```
Скрипт использует компилятор .NET Framework `csc.exe`, оптимизирует сборку и автоматически копирует готовую `RaftTrainer.dll`:
1. В папку игры: `D:\Raft\Raft_Data\Managed\RaftTrainer.dll`
2. Копию на Рабочий стол: `%USERPROFILE%\Desktop\RaftTrainer.dll`
3. В папку OneDrive Рабочего стола (при наличии)

### Вариант 2: Сборка через .NET CLI
```powershell
dotnet build -c Release
```

## 🎮 Установка в игру

1. Скомпилируйте проект или скопируйте готовую `RaftTrainer.dll` в директорию `Raft\Raft_Data\Managed\`.
2. Добавьте вызов `RaftTrainer.TrainerGUI.Init()` в метод инициализации игры (например, в `Assembly-CSharp.dll` через dnSpy).
3. Запустите игру. По умолчанию меню чита скрыто, нажмите <kbd>F4</kbd> или <kbd>Insert</kbd> для вызова.
